# alltests 확장 계획: 종합 기출 시험 사이트

작성 2026-11-19 · 상태: **0-A 완료 (2026-11-19)**, 다음 단계 승인 대기

## 원칙

- **문제 먼저, 해설은 단계적으로.** 문제와 공식 정답은 수집되는 대로 바로 올립니다(풀이·채점 가능). 해설은 단계마다 정해진 양만큼 채우고, 그 전까지는 "해설 준비 중"으로 표시합니다.
- **해설 1단계 = 약 1,800문항.** 지금까지의 실측 기준입니다(1,660문항 → 5시간 한도 60%, 1,890문항 + 검수 수정 → 82%). 1,800문항이면 검수까지 포함해 **5시간 한도의 60~70%**입니다.
- **주간 한도가 실제 병목입니다.** 해설 1단계마다 주간 한도의 약 10%를 씁니다. 다른 작업을 감안하면 **일주일에 해설 4~5단계**가 현실적인 최대치입니다(현재 주간 59% 사용, 11/22 초기화).
- **공공누리 1·3유형을 대상으로 합니다.** 수집할 때 게시물마다 유형을 기록하고, 2·4유형이나 표시가 없는 게시물은 보류합니다. 아래 "저작권 정리"를 참고하세요.
- 각 단계가 끝나면 검수 스크립트, 실제 사이트 확인, 사용량 보고를 마친 뒤 다음 단계 승인을 받습니다.

- 논술형 2차(변리사, 세무사, 노무사 등)는 모의고사 대상에서 뺍니다.

## 저작권 정리 (진행 전 확인 부탁)

- **공공누리 1유형:** 출처만 표시하면 상업적 이용과 변형이 모두 가능합니다. 다만 변형한 자료는 공식 문제·정답으로 오인되지 않게 표시해야 합니다.
  - 그래서 모든 문항에 "출처: 한국산업인력공단(큐넷), 공공누리 1유형"을 표시합니다.
  - AI 해설에는 "공식 해설이 아님"을 계속 표시합니다.
- **공공누리 3유형(공무원 시험 일부): 1유형과 같은 방식으로 적용** (2026-11-19 결정)
  - 원본 PDF의 문항 영역을 내용 수정 없이 그대로 잘라 보여 주고, AI 해설은 별도로 덧붙입니다.
  - 문항마다 출처(기관·게시물·공공누리 유형)를 표시하고, AI 해설은 공식 해설이 아님을 계속 표시합니다.
  - 수집기는 게시물마다 공공누리 유형을 기록해 둡니다. 나중에 기관 답변이나 기준이 바뀌면 3유형만 골라 조정할 수 있게 하려는 것입니다.
  - 2·4유형(비상업)이나 표시가 없는 게시물은 계속 보류합니다.

## 단계

각 단계의 사용량은 5시간 한도 기준 추정치입니다. 실제로 쓴 양은 단계가 끝날 때마다 보고합니다.

### 0단계: 개발 (해설 없음, 각각 승인)

| 단계 | 내용 | 추정 사용량 |
|---|---|---|
| **0-A 사이트 구조 개편** ✅ | 시험 분류 체계(분야 → 시험 → 연도·과목), 4지/5지 선다, 시험별 시간·과목 구성, 시험별 첫 화면과 검색 페이지, 기존 PSAT 주소 유지 | 40~50% |
| **0-B 큐넷 수집기 (PDF, 2014년 이후)** | 목록·상세·다운로드, 공공누리 유형 기록, 정답표 OCR, 문항 분할(4지 대응), 띄어쓰기 복원, 매일 자동 갱신 | 40~60% |
| **0-C 공무원 시험 수집기** | 9급·7급·지방직, 공공누리 유형 기록, 중복 제거 | 30~40% |
| **0-D 옛 HWP 변환** | 2014~2019년 HWP·ZIP을 PDF로 바꾸는 경로 (도구를 먼저 조사하고, 안 되면 해당 연도는 보류) | 20~40% |

0-B까지 끝나면 해설 없이도 큐넷 2014년 이후 PDF 시험을 바로 풀 수 있습니다.

## 진행 방식

1. 다음 단계를 제안하면 승인해 주세요("0-A 진행" 같은 식으로).
2. 단계를 진행하고 끝나면 보고합니다: 결과, 검수 결과, 실제로 쓴 사용량.
3. 해설 단계는 5시간 한도가 초기화된 직후 시작하는 것이 좋습니다(한 단계가 한 창 안에 끝나도록).

## 진행 기록

- **0-A 완료 (2026-11-19).** 시험 카탈로그 `web/src/exams.json`(앱과 검색 페이지 생성기가 함께 씀), 첫 화면 `#/`(분야별 시험 목록), 시험별 첫 화면 `#/x/<시험 id>`, 4지·5지 선다, 시험별 제한 시간, 시험별 기록·오답노트, 시험별 검색 페이지 `/<시험>/`. 기존 PSAT 검색 주소 119개는 그대로 유지. 새 시험을 붙이려면 `exams.json`의 status를 "live"로 바꾸고, 문제지(`data/catalog.json`)에 `exam`, `group`, `choices`를 넣으면 됩니다.
- **0-B 진행 중 (2026-11-19 일시 중지).** 완료: 큐넷 수집기 `pipeline/qnet.py`(목록·상세·공공누리 유형·다운로드), 정답표 그림 추출 `pipeline/qnet_answers.py`(PDF 렌더링, HWP 그림 추출, 형식 검사), 4지선다·시작 번호 지정·세 자리 문항 번호 분할, 모든 시험 공통 `pipeline/build_index.py`(PSAT 결과 동일 확인). 시범 시험 관광통역안내사(gId 37) 2013~2026 파일 수집 완료, 정답표를 두 명이 따로 읽어 `data/qnet/37/answers_A.json`, `answers_B.json`에 저장(비교 예정).
  - 확인된 사실: 정답표는 PDF·HWP 모두 표 그림이라 글자로 뽑을 수 없음(로컬 OCR은 정확도 부족) → 읽어서 두 결과를 대조하는 방식. 문제지 PDF는 대부분 글자 추출 가능, 일부(공인중개사 2025·2026, 관광통역 2014 정기 등)는 스캔·특수 글꼴이라 별도 처리 필요. A형·B형 문제지는 내용이 같아 A형만 사용.
  - 남은 일: `pipeline/qnet_build.py`(게시물 제목·파일명으로 연도·정기/특별·교시·책형을 맞춰 정답과 연결, 과목 범위로 문제지 나누기, PDF 한 번만 복사하고 문제지가 `pdf` 필드로 공유), 앱의 `pdf`·원래 문항 번호(`orig`) 표시, 관광통역안내사 공개, 나머지 시험으로 확대, CI 매일 갱신(새 정답표는 API로 두 번 읽어 대조).
- **0-B 1차 확대 (2026-11-19).** 공인중개사·주택관리사보·경비지도사(1차)·사회복지사 1급·청소년상담사·물류관리사 공개. 정답표는 두 번 따로 읽어 다른 칸만 원본으로 다시 확인. 문항 나누기 개선: 표지·유의사항 쪽 건너뛰기, 큐넷 꼬리말·과목 제목(상자 포함) 제외, 머리말 없는 문서. 표본 59문항 눈으로 검수.
  - 아직 못 연 것: 사회복지사 2014~2017(문제지가 HWP), 공인중개사 2014~2015(다른 편집)·2025(글자 없음), 경비지도사 2차(선택과목별 번호), 주택관리사보 일부 연도(HWP·주관식 구성), 2013년 이전(공공누리 표시 없음).
- **0-B 2차 확대 (2026-11-19).** 공인노무사·감정평가사·세무사·관세사·변리사 1차 공개. 문항 나누기 개선: 1단/2단 판정 강화, 마지막 문항은 마지막 보기가 나오는 단까지, 꼬리말 형식 추가, 교시 표시 없는 파일은 과목 이름으로 연결. 표본 45문항 검수.
  - 못 연 것: 스캔본(노무사 2016·2018·2020·2021, 감평 2021, 세무사 2018 일부, 관세사 2021, 변리사 2020·2022 등), HWP 정답표만 있는 해(노무사 2024, 관세사 2015~2017).
- **0-C 공개 (2026-11-19).** `pipeline/gosi.py`: 인사혁신처 사이트에서 공무원 시험(exams.json 의 gosi=testCd) 과목별 행을 받아, 정답은 확정정답 게시물의 정답표 PDF(글자 추출)에서 읽고, 문제지 PDF 를 4지선다로 나눈다. 공개: 9급 485개(9,700문항), 7급 570개(12,865문항), 지방직 124개(2,480문항). 과목이 7개 이상인 시험은 연도별 화면에서 과목을 먼저 고른다. 표본 43문항 검수 → 본문 속 법령 이름(「형사소송법」 제6조…)을 과목 제목으로 오인해 문항이 잘리던 문제 발견·수정(제목은 한 줄에 홀로 있을 때만 인정) — 공무원 55개, 세무사 행정소송법 4개 문제지가 함께 고쳐짐. 남은 일: 2016(책형 숫자)·2020(정답표 없음) 등 정답 못 읽은 행, 문항 나누기 실패분, 게시물별 공공누리 유형 확인, 빌더에 PDF 압축 넣기, CI 매일 갱신에 gosi 연결.
